# SGM Studios — REAPER Scripts

Free REAPER ReaScripts by **Scott Mills / SGM Studios**, distributed via [ReaPack](https://reapack.com).

## Installation

1. In REAPER: **Extensions** → **ReaPack** → **Import repositories…**
2. Paste this URL:

   ```
   https://raw.githubusercontent.com/sgm-audio/sgm-studios-reapack/main/index.xml
   ```

3. **Extensions** → **ReaPack** → **Browse packages…** → install **SGM Studios Essentials** and/or **SGM Rule of 30 Bundle** → click **Apply**

## Bundles

| Bundle | Scripts | What it does |
|---|---|---|
| **SGM-Essentials** | 6 + shared library | Mix bus routing, one-click mastering, bass FX chain toggle, 4K theme + smart tools, DAW environment profiler |
| **Rule-of-30** | 3 + preset library | 48-track heavy metal session builder (Drop Bb, quad guitars), plugin chain presets, quad-DI phase alignment |

## Requirements

- REAPER 7.0+ (Lua 5.4)
- SWS/S&M Extension — optional (enables routing inspection in the DAW analyzer)
- All scripts use REAPER stock FX by default — no paid plugins required
